Django-CRM

Plataforma CRM moderna para gestión comercial - Presentación del equipo y software seleccionado

1. Objetivo del proyecto

Presentar de forma clara y atractiva un software CRM moderno (Django-CRM / BottleCRM)  que integra gestión de clientes, oportunidades, casos y facturación en una sola plataforma.  El objetivo es mostrar al equipo de trabajo y explicar el valor técnico y funcional de la solución.

2. Software seleccionado: Django-CRM

Información del software seleccionado

  • Nombre del Producto: BottleCRM (Open Source) - Django-CRM
  • Repositorio: https://github.com/AntonyCondori/Django-CRM
  • Dominio: Sistema CRM para gestión comercial integral, con ventas, soporte y facturación.
  • Complejidad: Media-alta. Plataforma full-stack con 7 módulos y arquitectura multi-tenant con PostgreSQL RLS.
  • Viabilidad Técnica y Legal: Licencia MIT, stack Django 5.x + SvelteKit 2.x, Docker Compose, PostgreSQL RLS y Redis.

Descripción general

Django-CRM es una plataforma CRM open source diseñada para startups y pequeñas empresas.  Combina un backend robusto basado en Django REST Framework con una interfaz moderna en SvelteKit.

Módulos principales

  • Leads: Seguimiento de prospectos en el ciclo de ventas
  • Cuentas: Administración de empresas y organizaciones clientes
  • Contactos: Gestión de personas y datos de contacto
  • Oportunidades: Seguimiento de deals y negociaciones
  • Casos: Gestión de soporte y atención al cliente
  • Tareas: Planificación, kanban y calendario
  • Invoices: Generación y gestión de facturas

Ventajas diferenciales

  • Multi-tenant con RLS: Cada organización tiene datos completamente aislados a nivel de base de datos
  • Seguridad: Autenticación JWT, gestión de permisos por equipos
  • Automatización: Tareas en segundo plano (Celery), integración con AWS SES para correos
  • Escalabilidad: Redis para caché, arquitectura preparada para producción
Open Source Multi-tenant Seguro Escalable Automatizado

3. Tecnologías principales

Backend

Django 5.x, Django REST Framework, PostgreSQL con Row-Level Security, JWT, Celery, Redis

Frontend

SvelteKit 2.x, Svelte 5, TailwindCSS 4, shadcn-svelte, Lucide icons

Infraestructura

Docker, AWS S3 (archivos), AWS SES (correos), PostgreSQL, Redis

Backend

API REST robusta con autenticación JWT, manejo de datos complejos y permisos granulares

Frontend

Interfaz moderna y responsive con componentes reutilizables y experiencia fluida

Base de datos

PostgreSQL con RLS para aislamiento de datos por organización a nivel de BD

Tareas asincrónicas

Celery + Redis para envío de correos, reportes y procesamiento en background
